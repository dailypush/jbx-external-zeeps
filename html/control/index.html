Connect the game

First-time setup only. Close the game before changing its files.

  1. Open the game's installation folder and find SlingShoot.swf.
  2. Copy the original into a separate backup folder.
  3. Replace it with the SlingShoot.swf included in this project's folder.
  4. Launch Zeeple Dome normally and start a challenge.

The modified file's compatibility with your game version still needs checking. If the game has trouble, restore your backup. See README.md in the project folder for the full setup and troubleshooting guide.
